# おうちモンテ活動カタログ 設計書

## 概要
モンテッソーリの教具・活動を紹介するカタログサイト。
- 管理者・編集者: WordPress 管理画面から記事を投稿・編集・削除
- 閲覧者: ログイン不要で閲覧（検索エンジンには表示させない）

## 技術構成
| 項目 | 内容 |
|---|---|
| CMS | WordPress |
| テーマ | オリジナルテーマ（デザインカンプを再現） |
| カスタムフィールド | SCF（Secure Custom Fields、無料・リピーター対応） |
| ローカル環境 | Docker（@wordpress/env） |
| Git 管理対象 | テーマ・設定ファイル |
| 動画 | YouTube 限定公開の URL を埋め込み |
| 検索除外 | meta robots noindex ＋ X-Robots-Tag ヘッダー |

## 画面
1. トップ（一覧）: 検索 / 領域タブ / 領域見出し / 案内文 / 小分類タブ / 絞り込み / カードグリッド（3列） / ページ送り
2. 教具詳細（例: ピンクタワー）
3. 活動詳細（例: ボール落とし）
4. 保存した活動（ブックマーク一覧）

## 投稿タイプ
### 教具 `tool`
- メイン画像（アイキャッチ）
- キャッチコピー
- 短い説明
- 取り入れる目安
- こんな子におすすめ（リスト）
- 直接目的 / 間接目的
- 教具の概要（本文）
- 育つ力（リスト）
- 提示方法（YouTube URL）
- 活用方法（リピーター: 見出し / 画像複数 / 本文）

### 活動 `activity`
- メイン画像（アイキャッチ）
- キャッチコピー
- 短い説明
- 取り入れる目安
- こんな子におすすめ（リスト）
- 活動の概要（本文）
- 用意するもの: 型紙ファイル / 材料リスト（名前・購入先URL・補足） / 画像
- 提示方法（本文 ＋ YouTube URL 任意）
- 難易度の上げ方（リスト）
- 関連する活動（投稿を選択）

## タクソノミー（両投稿タイプ共通）
- 領域 `area`: 微細運動 / 粗大運動 / 感覚教育 / 言語教育 / 数教育 / 文化教育
  - ターム設定: タブの色、見出し（例「指先の活動」）
- 発達段階 `stage`（階層あり）: 例）にぎる・つまむ期 > 把握反射
  - 親の段階 = 一覧の領域下タブ。ターム設定「表示する領域」で、どの領域のタブに出すか決める
  - 子の段階 = カードのサブタイトル、パンくず
- 手の動き `hand_motion`: 握る / つまむ / ひっぱる / 押す / 回す / 通す / はめる / はさむ / 貼る / ちぎる（11個目以降は「その他」）
  - カード左上のタグ、詳細のピル。ターム設定: アイコン画像
- 入手方法 `acquire`: 手作り / 購入 / 身近なもので代用 / レンタル

## 絞り込み
- 手の動き（複数選択）、入手方法（複数選択）、提示動画（あり/なし）
- 同じ項目内は「いずれか」、項目同士は「かつ」
- URL: `?period=<段階>&hand[]=<手の動き>&source[]=<入手方法>&video=yes|no`

## 権限
- 管理者: 全操作 ＋ ユーザー管理
- 編集者: 記事の投稿・編集・削除

## その他仕様
- ブックマーク: ブラウザ（localStorage）に保存。ログイン不要
- カードの再生アイコン: 動画 URL が入力されている記事に表示
- 「発達タイムライン」「発達記録シート」: 外部 URL をテーマ設定で入力
