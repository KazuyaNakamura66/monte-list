# おうちモンテ活動カタログ 設計書

## 概要

モンテッソーリの教具・活動を紹介するカタログサイト。

- 管理者・編集者: WordPress 管理画面から記事を投稿・編集・削除
- 閲覧者: ログイン不要で閲覧（検索エンジンには表示させない）

## 技術構成

| 項目               | 内容                                              |
| ------------------ | ------------------------------------------------- |
| CMS                | WordPress                                         |
| テーマ             | オリジナルテーマ（デザインカンプを再現）          |
| カスタムフィールド | SCF（Secure Custom Fields、無料・リピーター対応） |
| ローカル環境       | Docker（@wordpress/env）                          |
| Git 管理対象       | テーマ・設定ファイル                              |
| 動画               | YouTube 限定公開の URL を埋め込み                 |
| 検索除外           | meta robots noindex ＋ X-Robots-Tag ヘッダー      |

## 画面

1. トップ（一覧）: 検索 / カテゴリー / カテゴリー見出し / 案内文 / 小分類タブ / 絞り込み / カードグリッド（3 列） / ページ送り
2. 教具詳細（例: ピンクタワー）
3. 活動詳細（例: ボール落とし）
4. お気に入り（ブックマーク一覧）: 検索 / カテゴリー（すべて＋各カテゴリーで切り替え） / カードグリッド（3 列）

## 投稿タイプ

### 教具 `tool`

- メイン画像（アイキャッチ）
- キャッチコピー
- 短い説明
- 取り入れる目安
- こんな姿がみられたら（リスト）
- 直接目的 / 間接目的
- 教具の概要（本文）
- 育つ力（リスト）
- 提示方法（YouTube URL）
- 活用方法（リピーター: 見出し / 画像複数 / 本文）

### 活動 `activity`

- メイン画像（アイキャッチ）
- キャッチコピー
- 短い説明
- 取り入れる目安
- こんな姿がみられたら（リスト）
- 目的
- 活動の概要（本文）
- 用意するもの: ダウンロードリンク（PDF または URL・リンクの文字） / 材料リスト（名前・購入先 URL・補足） / 画像
- 作り方（リピーター: 手順。番号は自動、文中の改行を反映）
- 提示方法（本文 ＋ YouTube URL 任意）
- 難易度の上げ方（リスト）
- 関連する活動（投稿を選択）

## タクソノミー（両投稿タイプ共通）

- カテゴリー `area`: 微細運動 / 粗大運動 / 感覚教育 / 言語教育 / 数教育 / 文化教育
  - ターム設定: タブの色。一覧の大見出しはタブ名と同じ
- サブカテゴリー `stage`（階層あり）: 例）握る > 把握反射
  - 上の階層 = 一覧のカテゴリーの下に並ぶタブ。ターム設定「表示するカテゴリー」で、どのカテゴリーに出すか決める
  - 下の階層 = カードのサブタイトル、パンくず
- ラベル `hand_motion`: ターム設定「表示するカテゴリー」で、どのカテゴリーの絞り込みに出すか決める（すべて表示）
  - 微細運動・日常生活の練習: ひっぱる / 剥がす / 落とす / はめる / はめ込む / 通す / 押す / ひねる / 巻く / 両手を使う / あけ移す / そそぐ / 掛ける / 貼る / ちぎる / はさむ / とめる / 穴あけ / 折る / はさみ切り / 結ぶ・編む / 縫う / 握る
  - 粗大運動: 生まれてすぐ / 手を伸ばし始めたら / 移動し始めたら / 歩き始めたら / 歩行が安定したら
  - 感覚教育: 視覚 / 触覚 / 聴覚 / 嗅覚 / 味覚
  - 言語教育: 言葉のインプット / 言葉の認識が始まったら / 話し始めたら / 書く / 読む
  - 数教育・文化教育: タブ1
  - カード左上のタグ、詳細のピル
- 入手方法 `acquire`: 手作り / 購入 / 身近なもので代用 / レンタル

## 絞り込み

- ラベル（複数選択）、入手方法（複数選択）、提示動画（あり/なし）
- 同じ項目内は「いずれか」、項目同士は「かつ」
- URL: `?period=<段階>&hand[]=<ラベル>&source[]=<入手方法>&video=yes|no`

## 権限

- 管理者: 全操作 ＋ ユーザー管理
- 編集者: 記事の投稿・編集・削除

## 管理画面のメニュー

- カテゴリーごとに開閉: カテゴリー > すべて / 教具・活動 > 一覧 / 追加 / サブカテゴリー / ラベル / 入手方法
- 「すべて」は教具と活動をまとめた一覧（種類の列あり、入手方法の列なし）
- 一覧はそのカテゴリーの記事に絞り込み、追加画面はそのカテゴリーにチェックが入った状態で開く
- カテゴリーは 1 記事に 1 つ（単一選択）。指定がなければ最初のカテゴリーにチェック
- カテゴリーのメニューから追加すると、編集画面のカテゴリー欄はそのカテゴリーのみ。保存済みの記事は「変更する」で他を選べる
- サブカテゴリー・ラベルは選択中のカテゴリーのものだけ表示（編集画面・左メニューとも）
- カテゴリー・サブカテゴリー・ラベルは公開時に必須（下書きは未選択でも可。選択肢がないカテゴリーのサブカテゴリー・ラベルは対象外）

## その他仕様

- ブックマーク: ブラウザ（localStorage）に保存。ログイン不要
- 「発達タイムライン」「発達記録シート」: 外部 URL をテーマ設定で入力
