# 本番公開の手順

サーバーが決まったら、この順で進める。所要時間の目安は 1〜2 時間。

## 0. サーバーの条件
- PHP 8.1 以上、MySQL 8 / MariaDB 10.6 以上（一般的なレンタルサーバーなら問題なし。例: Xserver、ConoHa WING、ロリポップ ハイスピード以上）
- 無料 SSL（https）が使えること
- 自動バックアップがあると安心

## 1. WordPress を入れる
1. サーバーの管理画面で、ドメインを設定して **無料 SSL を有効化** する
2. 「WordPress 簡単インストール」などで WordPress を入れる
   - サイト名: おうちモンテ活動カタログ
   - 管理者のユーザー名は `admin` 以外にする。パスワードは長いものにする

## 2. テーマとプラグインを入れる
1. 手元で zip を作る: `npm run zip` → `dist/monte-list.zip` ができる
2. 管理画面 > 外観 > テーマ > 新規追加 > テーマのアップロード で zip を入れて **有効化**
3. 管理画面 > プラグイン > 新規追加 で次を入れて有効化
   - **Secure Custom Fields**（必須。入力項目に使用）
   - **WP Multibyte Patch**（日本語の検索などを改善）
4. テーマを有効化すると、分類（領域・発達段階・手の動き・入手方法）が自動で作られる

## 3. 設定
- 設定 > 一般: タイムゾーンを「東京」
- 設定 > パーマリンク: 「投稿名」を選んで保存
- 設定 > 表示設定: 「検索エンジンがサイトをインデックスしないようにする」にチェック（テーマ側でも noindex を出しているが念のため）
- サイト設定（左メニュー）: 発達タイムライン / 発達記録シートの URL、（使う場合）Google アナリティクスの測定ID
- 領域 > 各領域の編集: タブの色を確認

## 4. ユーザー
- ユーザー > 新規追加 で編集担当者を作り、権限グループを **編集者** にする
- 管理者は最小限の人数にする

## 5. 安全対策
- **ログイン保護**: プラグイン「Limit Login Attempts Reloaded」を入れる（ログインの総当たり攻撃を防ぐ）。サーバーに同様の機能（例: Xserver の「ログイン試行回数制限」）があればそれでもよい
- **バックアップ**: サーバーの自動バックアップを確認。なければプラグイン「UpdraftPlus」で週1回以上
- **自動更新**: WordPress 本体のマイナー更新は自動のまま。プラグインは自動更新を有効にしておく
- 使わないテーマ・プラグインは削除（WordPress 標準テーマを1つだけ予備で残す）

## 6. 記事の移行（ローカルで入力した場合）
- 方法A: 本番で入力し直す（記事数が少ないうちはこれが確実）
- 方法B: ローカルと本番の両方にプラグイン「All-in-One WP Migration」を入れ、ローカルで書き出し → 本番で読み込み
  - ※ 本番の設定・ユーザーも上書きされるので、本番で作業を始める前に行うこと

## 7. 公開後の確認
- [ ] https で開ける
- [ ] トップ・領域タブ・発達段階タブ・絞り込み・検索が動く
- [ ] 活動・教具の詳細ページが表示される
- [ ] しおり → 保存した活動に表示される
- [ ] ページのソースに `noindex` が入っている
- [ ] 編集者アカウントで記事の投稿・削除・並べ替えができる
- [ ] LINE に URL を送るとタイトルと写真が出る

## テーマを更新するとき
1. `npm run zip` で新しい zip を作る
2. 外観 > テーマ > 新規追加 > アップロード で同じ zip を入れ、「アップロードしたもので現在のものを置き換える」を選ぶ
